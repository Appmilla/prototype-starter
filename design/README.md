# design/

The Claude Design handoff for this prototype goes here: the exported folder as it comes out of Claude Design
(for example `source/build.py`, `source/src/*.html` and `source/project/components/`).

You don't need to put it here yourself. Give Claude the handoff, in the chat or as a folder of files, and ask it to
build the clickable prototype; Claude copies it into this folder.

When Claude reads the handoff it also writes `design/handoff-map.json`: the handoff's own list of screens and the
links between them. The screen map is checked against it before sign-off.

The template itself holds no design, so this folder is empty apart from this note.
