# Share with the client

Share the agreed version: what the designer has looked at and is happy with, not work in progress.

1. Make sure everything is committed and pushed, and the type check and lint pass (`npm run check`).
2. Note the version being shared: the current commit, and the screen count from `PROTOTYPE-MAP.md`.
3. Publish it and give the link.

> **PLACEHOLDER: how previews are published is not decided yet.**
>
> Until it is, don't invent a hosting service or set one up. Tell the designer plainly that publishing a link for
> clients isn't set up for this prototype yet, and offer what does exist: the preview link from this session
> (which only works while the session is running), or showing the client on a call. When the publishing method
> is decided, this step is replaced by it in the starter template and arrives with "update the tools".

Tell the designer which version they are sharing (in words: "the version with the new checkout screens") and,
once publishing exists, give the link to it.
