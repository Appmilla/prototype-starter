# Appmilla prototype starter

**Work in progress.** A GitHub template for clickable prototypes built from a Claude Design handoff.

Each new prototype is its own repository, created from this one with **Use this template**. Open it in Claude Code
(on the web or in the desktop app), add the Claude Design handoff, and ask Claude to build the clickable prototype.
The prototype runs on made-up data and is shaped so that its pages can later be copied into a production React app.

What is being built, and how, is in [BUILD-BRIEF.md](BUILD-BRIEF.md).
